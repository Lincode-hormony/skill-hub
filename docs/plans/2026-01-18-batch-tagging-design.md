# 批量标签与标签快速选择功能设计文档

**日期**: 2026-01-18
**作者**: Universal Skill Hub Team

## 概述

本文档描述了 Universal Skill Hub 的批量标签与标签快速选择功能的设计方案。该功能旨在提高用户管理大量 Skills 时的效率，特别是在导入系列 Skills（如 superpowers）和为项目批量选择 Skills 的场景。

## 功能目标

1. **批量打标签**：一次性为多个 Skills 添加相同的标签，便于按系列分组
2. **标签快速选择**：在项目管理中通过标签快速批量勾选相关 Skills
3. **智能标签识别**：安装时自动识别仓库来源并建议合适的标签
4. **追加模式**：新标签追加到现有标签，不影响已有分类

## 用户场景

### 场景 1：导入 superpowers 系列

1. 用户在安装页面输入 `obra/superpowers`
2. 点击预览，看到 12 个 Skills
3. 批量标签输入框自动预填 `superpowers`
4. 用户点击"安装"，所有 Skills 自动添加 `superpowers` 标签

### 场景 2：手动批量打标签

1. 用户已安装多个不同来源的 Skills
2. 点击"批量添加标签"按钮
3. 勾选 5 个与文档相关的 Skills
4. 输入标签 `文档处理`
5. 这 5 个 Skills 都添加了 `文档处理` 标签

### 场景 3：按标签快速选择项目 Skills

1. 用户创建新项目，点击"加载 Skills"
2. 看到标签快速选择区，显示 `superpowers (12)`, `obsidian (5)` 等
3. 点击 `superpowers`，12 个相关 Skills 自动勾选
4. 再点击 `obsidian`，额外勾选 5 个 Skills
5. 点击"链接到项目"，17 个 Skills 一次性添加

## 技术设计

### 后端 API

#### 新增接口

**批量更新标签**
```http
PUT /api/skills/batch/tags

Request:
{
  "skillNames": ["pdf", "xlsx", "docx"],
  "tags": ["office", "工具"]
}

Response:
{
  "success": true,
  "updated": 3
}
```

**标签统计**
```http
GET /api/tags/stats

Response:
{
  "tags": [
    { "name": "superpowers", "count": 12 },
    { "name": "obsidian", "count": 5 },
    { "name": "anthropics", "count": 8 }
  ]
}
```

#### 智能标签识别

```javascript
function extractTagNameFromRepo(repoUrl) {
  const repoName = repoUrl.split('/').pop().toLowerCase();
  const commonNames = ['skills', 'agents', 'ai-assistants', 'tools'];

  if (commonNames.includes(repoName)) {
    return repoUrl.split('/').slice(-2, -1)[0];
  }
  return repoName;
}

// 示例:
// obra/superpowers -> superpowers
// anthropics/skills -> anthropics
```

### 前端组件

#### 1. 批量打标签组件

**位置**: 安装 Skills 页面

**UI 结构**:
```
批量添加标签按钮
    ↓ (点击)
进入批量选择模式
    ↓
选择状态栏: "✓ 已选择 N 个 Skills"
    ↓
下一步按钮 → 标签输入弹窗
```

**标签输入弹窗**:
```
┌──────────────────────────────────────┐
│  批量添加标签                        │
│                                      │
│  为选中的 N 个 Skills 添加标签:      │
│                                      │
│  标签: [              ]              │
│       💡 多个标签用空格分隔           │
│                                      │
│  这将追加到现有标签                  │
│                                      │
│  [取消] [确认添加]                   │
└──────────────────────────────────────┘
```

#### 2. 安装弹窗增强

**新增字段**:
```
┌─────────────────────────────────────────────────────────┐
│  从 obra/superpowers 预览到的 12 个 Skills              │
│                                                         │
│  📦 批量标签: [superpowers        ]                     │
│  💡 安装后这些 skills 将自动添加此标签                   │
│                                                         │
│  [取消] [安装 N 个 Skills]                              │
└─────────────────────────────────────────────────────────┘
```

#### 3. 标签快速选择组件

**位置**: 项目管理页面，"加载 Skills"按钮下方

**UI 结构**:
```
┌─────────────────────────────────────────────────────────────┐
│  🏷️ 按标签快速选择:                                         │
│  [superpowers (12)]  [obsidian (5)]  [anthropics (8)]      │
│  ✓ 已通过标签勾选 12 个 Skills                              │
└─────────────────────────────────────────────────────────────┘
```

**标签按钮状态**:
- 未选中: 灰色背景，显示 `标签名 (数量)`
- 已选中: 蓝色渐变背景，显示 `✓ 标签名 (数量)`

**交互逻辑**:
- 点击标签 → 勾选所有包含该标签的 Skills
- 再次点击 → 取消勾选
- 支持多选，OR 逻辑累积勾选
- 无标签的 Skills 仍可手动勾选

## 边界情况处理

1. **空标签输入**: 用户未输入任何标签时，提示"请输入至少一个标签"
2. **标签已存在**: 追加模式，不检查重复，保持简单
3. **网络错误**: 批量操作失败时显示具体错误信息，支持重试
4. **部分成功**: 批量操作时部分失败，显示成功/失败数量
5. **无标签场景**: 标签快速选择区显示提示信息

## 设计原则

1. **YAGNI**: 只实现必要功能，避免过度设计
2. **渐进增强**: 不影响现有功能，纯增量添加
3. **用户控制**: 自动识别作为建议，用户可修改
4. **操作可逆**: 标签可随时编辑或删除
5. **性能优先**: 批量操作使用单次 API 调用
