Skill Hub 只有成为普通 Skill 的统一来源后才有意义。接管会整理现有安装，并让 Codex 与 Claude Code 从统一 Skill 库读取。

1
识别检查 Codex 与 Claude Code 的个人 Skill 目录，区分普通内容、系统内容、外部链接和冲突。
2
整理普通 Skill 经完整校验后迁入统一 Skill 库，相同内容只保留一份。
3
连接原安装位置改为指向 Skill 库的连接；重装时会恢复你此前选择的平台和项目连接。
4
保护系统与插件 Skill 不会接管；同名不同内容不会覆盖；失败时原目录会恢复。
